Give your agents a goal. Keep the work moving.

The open, local-first control plane for long-horizon agents and personal agent teams. Your runtime provides the model and tools; LoopX keeps objective, gates, todos, evidence and quota durable across sessions.

Get started GitHub LHTB results

Core tick — five commands

loopx quota should-run      # should this agent act now?
loopx todo claim            # who owns this slice?
loopx todo update           # what changed?
loopx refresh-state         # what should the next turn see?
loopx quota spend-slot      # account for a validated slice

Try LoopX

1 · Install

python3 -m pip install --upgrade loopx
loopx workflow-skills --install
loopx doctor

Python 3.11+ and Node.js 22.22.3+ required.

2 · Connect

cd /path/to/your-project
loopx connect
loopx status

Reuses existing state; keeps .loopx/ ignored.

3 · Start a goal

loopx start-goal --guided \
  --project . \
  --goal-text "Your objective"

Guided path when state is missing.

Why LoopX

objective / issue / project │ ▼ LoopX state: objective + gates + todos + scope + evidence + quota │ ├─ human judgment needed? ── yes ─▶ ask a concrete question and wait │ ├─ safe fallback available? ──────▶ run one bounded agent slice │ ▼ Codex / Claude Code / Cursor / shell agent executes one turn │ ▼ write evidence + handoff + next todo ─▶ quota decides the next tick
